05  LIMITS AND REFERENCES
Basis: ASME B31.3-2018, 304.2.1. S, E, W, Y and the allowances are user inputs and require veriﬁcation against the code and the
project speciﬁcation. Bending thins the wall at the intrados; this report checks the required thickness at each point of the bend
rather than computing the geometric thinning, for which the code gives no equation. Miter bends (304.2.3), external pressure,
other sustained or occasional loads, fatigue, and remaining-life assessment are outside this report.
